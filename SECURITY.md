# Security Policy

## Reporting a vulnerability

**Do not open a public issue.** Report privately through this repository's security advisory form.

Include what you found, how to reproduce it, and what an attacker could achieve. You will get an
acknowledgement within seven days.

## Scope worth reporting

- Anything that causes a model provider credential to be read, stored or transmitted by AI Labs.
  AI Labs is designed never to hold one — it spawns each vendor's own CLI under the user's own
  login and stores only `${VAR}` references to service API keys.
- Escaping the per-agent tool allowlist, the workspace root, or venture-level data isolation.
- Prompt injection from untrusted input that alters platform policy or grants a capability.
- A path by which an agent browsing context reaches the owner browsing context's session, cookies
  or storage.
- Secret leakage into prompts, transcripts, logs, completion receipts, exports or generally
  queryable database fields.
- Bypassing an approval gate for a protected action, or replaying an approval.
- Any way to write real data into the repository that `npm run guard` does not catch.

## Out of scope

Findings that require an attacker to already have administrative access to the host, and reports
generated by a scanner with no demonstrated exploit path.
