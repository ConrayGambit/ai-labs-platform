# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full. The canonical text is authoritative; it is linked rather than copied so that it cannot
drift from the original through transcription.

## In short

Participants are expected to be respectful, to assume good faith, and to keep disagreement technical
rather than personal. Harassment, demeaning comments, and unwelcome attention are not tolerated, in
this repository or in any space where someone is representing the project.

## Enforcement

Report conduct concerns privately through this repository's security advisory form, which is the
project's confidential contact channel. Reports are handled discreetly and the reporter's identity
is not disclosed without their consent.

Maintainers may warn, temporarily restrict, or permanently remove a participant for behaviour they
judge inappropriate, threatening, offensive or harmful.
